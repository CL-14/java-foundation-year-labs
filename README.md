# Java Foundation Year Labs & Projects

A centralized repository containing practical lab assignments, command-line utilities, core control-flow exercises, and interactive mini-games developed during foundation-year Java coursework.

## Project Structure & Contents

### Core I/O & Basic Arithmetic
* **Age Calculator:** Prompts user input via `Scanner` to calculate birth years and ages (`Age.java`).
* **Basic Calculators:** Arithmetic operation handlers for addition, subtraction, multiplication, and division (`Calc_2.java`, `Calculator.java`).
* **Contact Formatter:** Standard user data collection and greeting utility (`Names.java`).
* **Rectangle Area Method:** Demonstrates modularity and error handling via custom static methods (`Methods.java`).
* **Postage Calculator:** Region-based shipping cost calculator using conditional logic (`postage_calculator.java`).

### Advanced Math & Number Theory
* **Compound Interest Calculator:** Financial interest projection tool using formatted decimal outputs (`Compound.java`).
* **Prime Number Finder:** Modulus-based prime number generator utilizing nested loops (`modulus.java`, `Prime_number.java`).

### String & Text Manipulation
* **Vowel Counter:** Efficient string character traversal and analysis (`Efficient_vowels.java`).
* **Text Reverser:** Array and string character reversal utility (`ReverseText.java`).

### Interactive Command-Line Games
* **Grade Calculator:** Switch-case grading system with robust validation loops (`Grade_calculator.java`).
* **Guessing Games:** Random number generation and color-guessing logic with attempt tracking (`Guessing_color_game.java`, `Hi_lo.java`, `Lottery_game.java`).
* **Magic 8 Ball:** Interactive fortune teller featuring custom thread delays for dynamic animation (`magic_ball.java`).
* **Casino Games:** Full-featured text-based wagering games with balance tracking, user feedback, and CLI pacing using `Thread.sleep` (`Roulette.java`, `Slot_Machine.java`).

## Tech & Requirements
* **Language:** Java (JDK 8+)
* **Standard Libraries:** `java.util.Scanner`, `java.util.Random`, `java.util.Arrays`, `java.text.DecimalFormat`
* **Execution:** Run any class via command line after compiling with `javac`.
